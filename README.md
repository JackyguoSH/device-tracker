# kept · 设备账本

用于记录电子设备投入、持有时间和日均成本的静态网页。摘要可以查看全部设备的成本走势、在用组合、成本排行和品牌投入。设备页支持搜索、品牌筛选、分组和时间线。

## 构建、运行与验证

```bash
npm ci
npm run dev
npm test
npm run build
npx playwright install chromium
npm run test:e2e
```

使用 Node.js 20.19+ 或 22.12+。当前页面位于 `index.html`，可以直接在浏览器中打开。Vite 构建将页面输出到 `dist/`，`npm run preview` 可预览生产构建。静态托管的发布目录为 `dist/`，兼容子目录。Cloudflare Workers 使用仓库现有的 `npm run deploy` 命令。

`src/` 保留上一版的源码，`npm test` 验证其中的成本和 CSV 逻辑。浏览器测试针对当前页面运行。也可以通过 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` 使用已安装的 Chromium。

## 统计口径

统计默认以打开页面时的本地日期为截止日，可在设置中调整。初始设备快照包含在用设备 10 台、归档设备 3 台，当前持有投入 **¥62,143.00**。

日均成本 =（购入金额 + 截至该日的追加投入 − 已收回的金额）÷ 使用天数。购入当天为第 1 天，使用天数截至停用或出售日。近一年净支出汇总截止日向前一个日历年内有日期的购入与追加，抵扣同期回收款。排行可切换日均和近一年净支出。

设备对比和在用组合共用三个时间范围。拖动或悬停竖线即可查看交点读数，在用组合曲线会标记购入事件。

## 浏览器存档

设备记录保存在当前浏览器和站点的 `localStorage`，可以在设置中通过 CSV 导入或导出。CSV 含品牌列，也可以导入旧版 CSV。升级会读取同一站点的旧版存档，归档已售 M1 MacBook Air，合并最新三笔购入，保留其余记录和旧存档键。

## 布局网格（v2.0.3）

`src/grid.css` 为统一布局层：桌面 ≥1024px 使用 12 栏 / 24px 栏间距，平板 768–1023px 使用 8 栏 / 24px 栏间距，手机 ≤767px 使用 4 栏 / 16px 栏间距。页面最大宽度 1536px，边距按 48 / 32 / 16px 收缩。模块间距以 8px 为基本节奏。

表头与设备行共享列定义、16px 内边距和轨迹边界。桌面详情图表与事件分为 8 / 4 栏；平板与手机纵向排列。手机设备名称和成本各占 2 栏，轨迹占满 4 栏，支持名称换行和年均长金额。

## v2.0.4

设备详情改为独立弹窗：桌面居中、手机全屏。点击支出刻度仍会定位对应事件与日期；背景列表保持原位。支持 Esc、关闭按钮与桌面遮罩关闭；详情内编辑使用第二层弹窗，关闭后保留详情并保持背景滚动锁定，最终关闭恢复列表滚动与焦点。

已通过浏览器实测：桌面打开 / Esc 关闭、390px 竖屏详情、嵌套编辑关闭、背景滚动锁与恢复。`outputs/` 的桌面和手机截图为最新验证记录。
